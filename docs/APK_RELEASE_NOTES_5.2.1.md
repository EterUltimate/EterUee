# EterUee 5.2.1 APK 更新说明

## 短说明

EterUee 5.2.1 聚焦角色扮演模块、主题系统、前端体验和启动性能。此版本新增角色卡、世界书、预设的可视化编辑能力，完善 Tavern 兼容支持，并提供多套主题预设与更柔和的高科技界面风格。

## 功能更新

- 新增角色卡可视化编辑界面，支持更清晰地维护角色基础信息、描述、标签和版本字段。
- 新增世界书可视化编辑界面，支持条目化管理设定、关键词、启用状态和扩展数据。
- 新增预设可视化编辑界面，便于管理模型参数、提示词结构和角色扮演配置。
- 增强 Tavern 生态兼容，保留角色卡、世界书和聊天元数据中的扩展字段，减少导入导出时的信息丢失。
- 支持角色卡导出版本选择，可按 v1、v2、v3 格式输出。
- 新增多主题预设：柔和毛玻璃、极简、Claude 风格、ChatGPT 风格、Gemini 风格。
- 重构前端视觉风格，从硬朗赛博朋克调整为更柔和的 hitech 风格，增加圆角、毛玻璃和更自然的动效。
- 优化主题设置入口，可在显示设置中切换和调整主题。
- 恢复并统一应用品牌命名为 EterUee。
- 引入启动链路优化和 release 预编译任务，提升冷启动与首屏加载体验。

## 修复与改进

- 修复主题、输入栏、会话提示词注入、Mermaid 显示和动态卡片渲染相关问题。
- 改进移动端 Web UI 的布局适配与交互反馈。
- 修复 Android Studio / Gradle 环境下 pnpm 构建路径问题。
- 扩展文件上传后缀白名单。
- 合并 RikkaHub 2.2.0 至 2.2.4 之间的相关改动，并保留对 RikkaHub 项目的感谢。

## 构建信息

- 应用名：EterUee
- 包名：`com.eterultimate.eteruee`
- 版本名：`5.2.1`
- 版本号：`156`
- 最低 Android 版本：Android 8.0 / API 26
- 目标 Android 版本：API 37
- APK 架构：`arm64-v8a`、`x86_64`、Universal
- 签名验证：APK Signature Scheme v2

## 安装建议

- 日常手机安装优先使用 `app-arm64-v8a-release.apk`。
- 模拟器或 x86_64 设备使用 `app-x86_64-release.apk`。
- 不确定设备架构时使用 `app-universal-release.apk`。
