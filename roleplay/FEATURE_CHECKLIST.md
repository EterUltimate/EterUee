### 🔧 技术栈

- **UI**: Jetpack Compose + Material Design 3
- **状态管理**: Kotlin Flow + StateFlow
- **异步**: Kotlin Coroutines
- **依赖注入**: Koin
- **数据库**: Room (SQLite)
- **文件存储**: JSONL 格式
- **AI 集成**: SSE (Server-Sent Events)
- **架构模式**: MVVM + Clean Architecture

## 🧪 测试指南

### 前置条件

1. **编译项目**
   ```bash
   ./gradlew :app:assembleDebug
   ```

2. **安装到设备/模拟器**
   ```bash
   adb install app/build/outputs/apk/debug/app-debug.apk
   ```

### 测试场景

#### 1. 角色管理测试

**测试 1.1: 创建角色**
1. 打开应用，进入 RolePlay 模块
2. 点击"角色"标签
3. 点击 FAB（浮动操作按钮）创建新角色
4. 填写角色信息：
   - 姓名：测试角色
   - 描述：这是一个测试角色
   - 性格：友好、幽默
   - 开场白：你好！我是测试角色
5. 上传头像（可选）
6. 点击保存
7. **预期结果**: 角色出现在列表中

**测试 1.2: 编辑角色**
1. 在角色列表中点击刚创建的角色
2. 修改角色描述
3. 点击保存
4. **预期结果**: 修改后的内容正确显示

**测试 1.3: 删除角色**
1. 长按角色卡片
2. 确认删除对话框
3. 点击确认
4. **预期结果**: 角色从列表中消失

#### 2. 世界书测试

**测试 2.1: 创建世界书条目**
1. 切换到"世界书"标签
2. 点击 FAB 创建新条目
3. 填写信息：
   - 名称：魔法学院
   - 关键词：魔法、学院、巫师
   - 内容：这是一所培养巫师的魔法学院...
4. 点击保存
5. **预期结果**: 条目出现在列表中

**测试 2.2: 关键词匹配**
1. 在聊天中发送包含"魔法"的消息
2. **预期结果**: 世界书内容自动注入到 AI 上下文

#### 3. 群组管理测试

**测试 3.1: 创建群组**
1. 切换到"群组"标签
2. 点击 FAB 创建新群组
3. 填写群组名称：测试群聊
4. 添加至少 2 个角色作为成员
5. 点击保存
6. **预期结果**: 群组出现在列表中

**测试 3.2: 群聊功能**
1. 点击进入群组
2. 发送消息
3. **预期结果**: 所有群组成员轮流回复

#### 4. 聊天功能测试

**测试 4.1: 发送消息**
1. 从角色列表点击一个角色开始聊天
2. 在输入框输入消息
3. 点击发送按钮
4. **预期结果**: 
   - 用户消息显示在右侧
   - AI 开始生成回复（显示"生成中..."）
   - AI 回复逐字显示（流式效果）
   - 完成后显示在左侧

**测试 4.2: 重新生成**
1. 等待 AI 回复完成
2. 点击消息下方的"重新生成"按钮
3. **预期结果**: 
   - 原回复被替换
   - 新的流式生成开始

**测试 4.3: 删除消息**
1. 点击消息下方的"删除"按钮
2. **预期结果**: 消息从列表中消失

**测试 4.4: 错误处理**
1. 断开网络连接
2. 尝试发送消息
3. **预期结果**: 显示错误提示 Snackbar

### 性能测试

**测试 5.1: 大数据量**
1. 创建 50+ 个角色
2. 创建 100+ 条世界书条目
3. 进行长对话（100+ 条消息）
4. **预期结果**: 
   - 列表滚动流畅（60 FPS）
   - 无内存泄漏
   - 加载时间 < 2 秒

**测试 5.2: 图片加载**
1. 为多个角色上传高清头像
2. 快速滚动列表
3. **预期结果**: 
   - 图片缓存正常
   - 无 OOM（内存溢出）

### 边界测试

**测试 6.1: 空状态**
1. 删除所有角色
2. **预期结果**: 显示空状态提示和创建按钮

**测试 6.2: 超长文本**
1. 输入 10000+ 字符的消息
2. **预期结果**: 
   - 输入框正常显示
   - 消息气泡正确换行

**测试 6.3: 特殊字符**
1. 在角色名称中使用 emoji、中文、特殊符号
2. **预期结果**: 正常显示，无崩溃
